# oiia — 바로타 (Baro-ta)

> 바로 찾고, 바로 타다 — AI Agent 기반 길찾기&예매 원스톱 서비스

2026 AI·SW중심대학 디지털 경진대회 SW부문 · 팀 **oiia** (임창건 · 홍동완 · 박현빈, 컴퓨터융합학부)

## 서비스 개요

대중교통 예매의 IT 격차를 해소하는 AI Agent 서비스입니다.

1. **AI 대화형 입력** — 챗봇이 출발지·도착지·도착 일시 등 필수 파라미터를 유도·추출
2. **최적 경로 추천** — 소요시간 · 매진 여부 · 희망 도착시각과의 시간차 기반 적합도 산출
3. **취소표 자동 조회** — 랜덤 주기 조회로 서버 부하 최소화, 이용약관 준수 범위 내 동작
4. **결제 직전 제어권 반환** — 자동 예매는 결제 직전까지만, 최종 결정은 항상 사용자

## 저장소 구조

```
oiia/
├─ baro-ta/       # 메인 앱: React(Vite+TS) 클라이언트 + Express API 서버
├─ prototypes/    # 단일 파일 HTML 프로토타입 (발표·시연용, 의존성 없음)
│  ├─ baro-ta-web.html         # 데스크탑 웹 (반응형: 700px 이하 모바일 모드)
│  └─ baro-ta-prototype.html   # 모바일 폰 프레임 데모
└─ docs/          # 기획 산출물 (예선 발표자료)
```

## 빠른 시작

```bash
cd baro-ta
npm install
npm run dev     # 백엔드(4000) + 프론트(5173) 동시 실행
```

http://localhost:5173 접속 — `?demo`를 붙이면 서울→부산 시연이 자동 재생됩니다.

단일 파일 프로토타입은 `prototypes/*.html`을 브라우저로 열면 바로 동작합니다.

자세한 구조와 API 명세는 [baro-ta/README.md](baro-ta/README.md)를 참고하세요.
