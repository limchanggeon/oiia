1.서비스 정의
노령세대(50–70대)가 말로 여정을 이야기하면, AI가 KTX·SRT·고속·시외버스를 통합 검색해 매진을 걸러내고 예매 가능한 경로 2–3개만 큰 글씨로 보여준 뒤, 좌석 선점(열차 등 가능한 수단에 한함)까지 대신하고 결제만 사람이 하는 이동 비서.

3. 기능명세

FR-1 음성·간단 입력
설명 - 첫 화면에서 텍스트 입력 or 마이크 버튼(또는 큰 버튼 입력)으로 여정을 자유 발화로 받는다.
입력 - 텍스트 입력 or 마이크 버튼 선택후 오디오 입력
출력 - 텍스트 or 발화 텍스트(STT)
동작 - 구글 검색창이나  GPT/클로드와 같은 바 형태의 입력창 내에 텍스트를 입력하거나, 옆에 마이크 버튼을 눌러 음성입력.

FR-2 LLM 슬롯 추출
설명 - 텍스트 or 발화 텍스트에서 슬롯을 JSON으로 추출
입력 -  출발지, 도착지, 날짜, 시간, 인원
출력 - {departure, arrival, date, ...}
동작 - 필수 슬롯 = 출발지·도착지·날짜. 시간대 기본값 '아침', 인원 기본값 '어른 1명'. 날짜 자연어 해석("다음 주 화요일", "설 전날"). 출발지는 위치 정보로 기본값

FR-3  선택형 되묻기
설명 - 빈 필수 슬롯이 있으면 LLM이 선택지 2–3개를 포함한 질문 1개를 생성
입력 - 입력	미충족 슬롯 목록, 현재 슬롯 상태, 대화 이력
출력-{question: string, options: [{label, slot_value}] (2–3개), target_slot}
규칙 - 
1.한 번에 하나만 묻기 
2.열린 질문 금지 — 반드시 선택지 제시 
3.⑤ 버튼 라벨은 명사형/명령형 — [아침 출발] ○ / [아침에 출발하시겠어요?] × (질문형 라벨은 주체 혼동 유발)
토의가 필요한 사항 - 
1. 3번이상 반복되면 사용성 급감. - 예외 처리를 어떻게 할지 회의 필요

FR-4 확인 요약
설명 - 검색 실행 전, 이해한 여정을 큰 글씨로 재확인
동작 - "7월 15일 화요일 아침 / 대전 → 부산 / 어른 1명" 형식. [네, 맞아요](주 버튼) / [고칠게요](부 버튼) → 슬롯별 수정 버튼

FR-6. 전 수단 통합 검색
설명 - 확정 슬롯으로 KTX·코레일 일반열차·SRT·고속버스·시외버스 시간표·요금을 통합 조회
출력 - 후보 경로 목록 (수단, 출발/도착 시각, 소요시간, 요금(할인 반영), 환승 수)
예외 - 개별 API 장애 시 해당 수단 제외 + "일부 교통편은 확인하지 못했어요" 고지후 재검색 선택 버튼

FR-7. 매진 확인·자동 제외
설명 - 후보 경로의 좌석 가능 여부를 확인해 매진 경로를 목록에서 제외
출력 - 이동수단 매진판정된 후보 목록
예외 - 실조회 실패(anti-bot 변경 등)시 어떻게 대처?

FR-8. 여정 재조합 엔진
설명 - 1순위 수단이 매진이면 타 수단·환승 조합으로 대체 여정을 생성
입력 - 확정 슬롯, 매진 판정된 후보 목록, 제약값(총 소요시간 ≤ 직결 최속편의 1.5배, 갈아타기 ≤1회, 환승 대기 ≥20분)
알고리즘 - ?

FR-9. 경로 제시 화면
설명 - 예약 가능한 경로를 카드로 제시
카드 구성 - 수단 아이콘+이름, 출발 시각(가장 크게), 도착 시각, 총 요금, 갈아타기 여부.

FR-10. 좌석 선점
설명 - 선택한 경로의 좌석을 예약(결제 전) 상태로 확보. 
구현 - 
열차: korail2/SRTrain reserve → 예약번호·운임·결제 기한 수신.
고속버스, 시외버스 - 예약 시스템 존재x 어떻게 대처?
선점 성공 문구 -  "자리를 잡아뒀어요"  "아직 돈은 나가지 않았어요"  "○○분 안에 결제하지 않으면 자동으로 취소되고, 돈은 한 푼도 나가지 않아요" — 화면 제공. 기한은 API가 반환한 실제 값 사용.
좌석 선택 - 예약 가능한 자리중 어떤자리를 예매할건지?
금지 - 결제 자동화 금지(카드정보 입력·저장·대리결제 일절 없음).
예외 - 선점 실패(경합 매진) → "방금 자리가 나갔어요" + "다른 길을 찾아볼까요?" 동의 후 FR-8 재조합.

FR-11. 결제 연결 ?

FR-13. 탑승 안내
설명 - 결제 완료 확인 후 최종 승인된 여행경로 저장후 안내
알림 - 전날 저녁·당일 아침(출발 2시간 전). 예매 완료 시점에 "전날 저녁과 당일 아침에 알려드릴게요" 기대 설정
토의사항 - 어떤방식으로 알림을 보낼지?

FR-15. 내 예매 확인
설명 - 앱 재진입 시 진행 중인 예약·부탁 상태를 즉시 확인
동작	첫 화면에 진행 중 예약이 있으면 "결제를 기다리는 표가 있어요 — ○○분 남았어요" 카드를 최상단 노출. 탭 시 예약 상세(경로·예약번호·결제 마감 시간·[결제하러 가기]/[취소하기]). 결제 완료된 표는 탑승 안내(FR-13)로 연결.
